# IDEA File Tree for Godot

IDEA File Tree adds a compact, JetBrains-inspired project tree to the Godot
editor. Clear hierarchy lines, tighter row spacing, folder-first sorting, and
native resource icons make deeply nested projects easier to understand.

The plugin adds a separate **Project** dock and does not modify project assets
or replace Godot's built-in FileSystem dock.

## Enable

Open **Project > Project Settings > Plugins** and enable **IDEA File Tree**.
